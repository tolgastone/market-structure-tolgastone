# v1.2.0 — Break Tolerance

Released 2026-11-08.

## Added

- **Break tolerance:** None, Percent or ATR, independent of Close / High-Low break source.
- Configurable boundary-relative percentage, ATR period and ATR multiplier.
- Optional **T** markers above/below candles whose tested source crossing falls short of the tolerance threshold. Markers are hidden by default.

## Structural behavior

None is the default and retains the previous structural behavior. A zero percentage or zero ATR multiplier also disables filtering.

With a nonzero tolerance, a structural break must strictly exceed the selected distance beyond the reference high or low. The same rule applies to normal BOS/CHoCH breaks and opposite-boundary interruptions. Filtering can remove or delay a break and change the subsequent swing chain, including the swings used by Fibonacci and Swing Zones.

ATR distance uses the previous closed bar's Wilder ATR on the chart timeframe. It refreshes each bar rather than remaining fixed per swing. Positive ATR mode waits until that sample is available. Equality at a threshold does not qualify; thresholds are not rounded to ticks.

For an accepted interruption in a filtered mode, the break drawing retains the direction accepted before the reference swing changes.

## Display and timing

T means a crossing rejected by the selected tolerance, not a liquidity-sweep classification. It follows the selected Close or High/Low source and can repeat on later bars. An accepted break suppresses T in that direction on the same execution.

Close still selects the current price source; it does not wait for bar close. Open-bar structure and T marks remain provisional. Working boundary arrows show the original working-swing boundaries, not tolerance thresholds.

## Preserved

Cement initialization and completion rules, FVG maintenance and logarithmic Fibonacci/Swing Zones geometry are unchanged. No fixed right-hand pivot confirmation window is added.
